FlowState: Be, places that fold

    Five places, one drawing

    Each place is a word and a pen stroke: heavy for First, thinner down, dashed and dotted for the shelves. Example data, live.

    How this is built
    Listsrc/ui/be/Be.tsx draws slots(t, folded, lifted) (be/tiers.ts): each place a heading (.fs-be-head), then its rows or a landing rule.
    MarksStrokes 3px, 2px, 1px ink, dashed and dotted print. Words at --fs-first (28px, the one new token), --fs-title, --fs-ink on one rule.
    DemoThe real app (design/folds/src, the tiers walkthrough's seed and touch), storage in memory, no network, today pinned to 11 / 12.

    Tap a heading to fold it

    The stroke lifts and the place's words are written on its one line.

    How this is built
    FoldThe heading is a button with aria-expanded. Folding takes the rows at once; opening fades them in over --t-page (.unfold), not the Fold part, so the list stays one flat run for the drag.
    DrawnThe stroke or the run is drawn over --t-draw on the tapped heading only (.drawn).
    KeptSettings.beFolded, a clear optional field, no schema bump; isFolded defaults the tiers open and the shelves folded.

    Fold them all to see the whole of me

    Five lines, every word, nothing counted.

    How this is built
    RunrunOf(rows): words in list order, a middle dot between, cut with an ellipsis. Folded headings sit on consecutive rules. Never a count (rule 15).

    Hold one to lift it

    Open places end in a landing rule; a folded place is its own.

    How this is built
    LiftuseLongPress, open values fold; slots(t, folded, lifted) keeps every fold, ends open places in .fs-be-land and dashes folded lines (.land).
    DemoTouch pointer events dispatched on the real row, as test/e2e/be-drag.spec.ts; no pointerup, so it stays held.

    Carry it into an open tier

    It takes that tier's size as it crosses and lands where I hold it.

    How this is built
    Geometryui/be/drag.ts: aim runs target(boxes, top, feet) over the collapsed slots; carry draws the list; tick('tier') on crossing.
    SteadyA row swaps past a heading as past a row, at half the other's height, so it never rocks between two places.

    Or over a folded line

    Its word joins the end of the line while I hold it there.

    How this is built
    FingerfingerOn(boxes, y, riding): a finger on a folded line is that place's foot (feet); its riding slot counts as the line, so a still finger stays.
    DrawnThe row rides .infold under the line, one rule tall; its word is .riding, last in the run, in italic.
    ReachFolding the tiers between makes a long carry a short one.

    It lands and the line stays folded

    Third is empty now, so it keeps a dashed rule to land on.

    How this is built
    DropplaceValue(id, to, index) and the drop tick. A drop never changes a fold: on a folded line the row goes into the run.

    Tap a word to open it

    The open value is as it is today; with the rest folded it has the page.

    How this is built
    SameShadow, looks, the five words, champions, Said, Call a council, grown by the Fold part. One of the five words carries it to a place's foot and opens that place.
    Link#/be/:id opens its place for the visit, without writing beFolded.

    Resting and Legacy fold the same way

    A dashed stroke for what I put down, a dotted one for what I used to hold.

    How this is built
    ShelvesThe shelf slot kind is gone: all five places are heading slots. An empty shelf shows only while a value is lifted, at its kept fold, its landing rule at the foot.

    In Still, only what comes first

    Unchanged: no headings, no strokes, nothing folds or lifts.

    How this is built
    StillstillValues, DESIGN.md rule 13. First is folded here, and its words still show.
