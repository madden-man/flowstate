    My values start in the middle

    Nothing is ranked for me: First and Third wait on dashed rules. Example data, live.

    How this is built
    Listsrc/ui/be/Be.tsx draws slots() (be/tiers.ts) from tiers() in model/values.ts: heading, rows, a landing rule when empty.
    DataNo schema bump, no flag: tier is optional and absent reads as Second; status gains 'legacy'.

    Hold one to lift it

    Open values fold, every tier ends in a rule to land on, and Resting and Legacy open.

    How this is built
    LiftuseLongPress over --t-hold; the lift empties open at once and slots(t, shelf, true) adds every landing rule.
    DemoTouch pointer events dispatched on the real row, as test/e2e/be-drag.spec.ts; no pointerup, so it stays held.

    Carry it over a heading

    One tick as it crosses into First, one as it lands.

    How this is built
    Geometryui/be/drag.ts: collapse and target turn slot rects and the row's top into { to, index }; a heading is passed as a row is.
    Touchtick('tier') and bell('tier') on crossing; placeValue and tick('drop') on release.

    The order they matter in

    The heading and the size of the word say the tier; nothing is numbered.

    How this is built
    Sizes.fs-value-t1 to t3: --fs-manifesto, --fs-title, --fs-ink. No new token.
    OrderOne order sequence across every value, sorted by status, tier, order; held() follows it for councils.

    Or tap where it belongs

    Five words on an open value move it without a drag, and say since when.

    How this is built
    WordsPLACE_WORDS; a tap is placeValue(id, to) to the foot, travelling through parts/Turn. The keyboard and VoiceOver path.

    Put one down for now

    On Resting a value waits undated, and comes back to the tier it left.

    How this is built
    PlaceplaceValue(id, 'resting') keeps tier, so returnsTo brings it back there; a drop leaves the shelf open.

    Let one go

    Carried to the foot, a value lands in Legacy.

    How this is built
    ScrollNear the list's edges edgeSpeed scrolls it by hand under the row, up to 14px a frame.
    PlaceplaceValue(id, 'legacy'); its champions are kept, not drawn, and Legacy is out of every council.
